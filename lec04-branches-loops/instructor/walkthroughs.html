Problem 1 · Ordered decisions

Classify a score without hiding the best grade

Use a descending else if chain to make the first-true rule visible.

5 minutesDemo file
GradeClassifier.java
Source §§3.1, 3.3–3.4

Students will learnTrace an ordered else if chain and explain why specific thresholds must appear before broad ones.
Problem

Read a score from 0–100 and print A, B, C, D, or F. The highest satisfied grade threshold must win.

Ask before typing

If score is 95 and the first test is score >= 60, can a later A branch run?

Expected prediction

No. The first condition is true, so Java runs that body and skips every later branch.

Say while tracing

“A chain is an ordered search. False continues; the first true result ends the search.”

GradeClassifier.javaStarter exposes the ordering bug
import java.util.Scanner;

public class GradeClassifier {
   public static void main(String[] args) {
      Scanner input = new Scanner(System.in);
      System.out.print("Score: ");
      int score = input.nextInt();
      String grade;

      // Logic bug: a broad test hides better grades.
      if (score >= 60) {
         grade = "D or better";
      }
      else if (score >= 90) {
         grade = "A";
      }
      else {
         grade = "F";
      }

      System.out.println("Grade: " + grade);
   }
}

Explain after the evidence

An else if chain is one mutually exclusive decision. Java tests top to bottom, executes the first true body, and skips the rest. Descending thresholds let each failed test establish an upper bound for the path that continues.

Logic error · recover

Keep the same input, reorder the thresholds from 90 down, rebuild, and rerun. The unchanged test makes the repair visible.

Transfer check

Predict 89, 90, 79, and 80.

Answer: B, A, C, B.

Explain after the evidence

Each comparison produces a Boolean. Inclusive operators keep their endpoint. AND narrows to the intersection of two requirements; OR broadens to either alternative. Java needs two complete comparisons rather than 13 <= age <= 19.

Compile-time detour · recover

Briefly try if (age = 19). One equals stores an int; two equals compare. Restore the range and rebuild.

Transfer check

import java.util.Scanner;

public class SentinelTotal {
   public static void main(String[] args) {
      Scanner input = new Scanner(System.in);
      int total = 0;
      int count = 0;

      System.out.print("Value (0 to stop): ");
      int value = input.nextInt();

      while (value != 0) {
         total += value;
         count++;
         // BUG: value never changes.
      }

      System.out.println("Count: " + count);
      System.out.println("Total: " + total);
   }
}

Explain after the evidence

A while loop checks before every iteration, so it may run zero times. The sentinel controls repetition but is not data. Termination depends on progress: the body must change a value used by the condition so a later check can become false.

Infinite loop · recover

Stop execution in the IDE, restore the last known loop body, add the input update, rebuild, and rerun the same sequence.

Transfer check

What prints if the first input is 0?

Count 0, total 0; the body never runs.

Explain after the evidence

A for loop groups initialization, continuation condition, and update. Use it when the number of iterations is known. The half-open range 0 <= i < n contains exactly N integer indices and matches Java strings and arrays.

import java.util.Scanner;

public class VowelCounter {
   public static void main(String[] args) {
      Scanner input = new Scanner(System.in);
      System.out.print("Lowercase word: ");
      String word = input.next();
      int vowels = 0;

      // Runtime bug: length is not a valid index.
      for (int i = 0; i <= word.length(); i++) {
         char letter = word.charAt(i);
         boolean isVowel = letter == 'a' || letter == 'e'
               || letter == 'i' || letter == 'o'
               || letter == 'u';
         if (isVowel) vowels++;
      }

      System.out.println("Vowels: " + vowels);
   }
}

Explain after the evidence

For a string of length N, valid indices are 0 through N - 1. The loop condition therefore uses i < word.length(). The branch is evaluated once per character, and the counter changes only for characters that satisfy the vowel policy.

Runtime error · recover

import java.util.Scanner;

public class ScoreReport {
   public static void main(String[] args) {
      Scanner input = new Scanner(System.in);
      final int SCORE_COUNT = 3;
      int total = 0;
      int passed = 0;
      int failed = 0;

      for (int i = 0; i < SCORE_COUNT; i++) {
         System.out.print("Score " + (i + 1) + ": ");
         int score = input.nextInt();
         total += score;

         if (score >= 60) passed++;
         else failed++;
      }

      double average = total / (double) SCORE_COUNT;
      System.out.printf("Average: %.1f%n", average);
      System.out.println("Passed: " + passed);
      System.out.println("Failed: " + failed);
   }
}

Explain after the evidence

The loop guarantees that every score is processed. The branch classifies one current score. The accumulator and counters preserve information across iterations because they are declared outside the body. The average is derived after the data set is complete.

Scope error · recover

Declare total inside the loop and observe that it cannot summarize earlier scores or be read afterward. Restore its outer scope and rebuild.

Transfer check

Which inputs test the pass boundary and extreme report states?

Use 59/60, then an all-pass set and an all-fail set.
