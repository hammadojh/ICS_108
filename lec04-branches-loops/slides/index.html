Part 2 · Choose a path

The same Boolean question can control two different shapes.

Branchif (condition)Ask once here

Choose whether a body executes, then continue.

Loopwhile (condition)Ask before every iteration

Run the body, return, and ask again.

Unifying model: evaluate a condition → select a path → update state → either continue or exit.

A branch selects. A loop rechecks and may repeat.§§3.1, 4.1

ICS 108Part 2 · Choose a path§3.1 if-else

if-else: exactly one of two paths

The two bodies are mutually exclusive.

if (age >= 18) {
   message = "Adult";
}
else {
   message = "Minor";
}
age = 20true → Adultelse skipped
age = 16false → Minorif body skipped

else means “every remaining case”; it has no condition of its own.

Two paths enter; one path executes.§3.1
ICS 108Part 2 · Choose a path§3.3 else-if

An else if chain is an ordered search.

if (score >= 90) grade = "A";
else if (score >= 80) grade = "B";
else if (score >= 70) grade = "C";
else grade = "Below C";
  1. 1Test from top to bottom.
  2. 2Run the first true body.
  3. 3Skip every remaining branch.
  4. 4Use else for what remains.

Put specific or high thresholds before broader ones. Order is part of the policy.

First true wins.§3.3

ICS 108Part 3 · Repeat while true§4.1 Loop model

Part 3 · Repeat while true

A loop sends control back to the question.

Each complete execution of the body is one iteration.

check conditiontrue ↓execute body↓update state↺ recheckfalse → continue after loop

Once an iteration starts, Java completes the body before checking the condition again.

Loop = condition + body + return path.§4.1
ICS 108Part 3 · Repeat while true§4.2 while

while checks before every iteration.

int count = 0;

while (count < 3) {
   System.out.println(count);
   count++;
}
initialize
Establish the state before the first check.
condition
True enters; false exits. It may be false initially.
update
Change state so a future check can become false.

A pre-check loop may execute zero times.

Initialization is outside; progress is usually inside.§4.2

ICS 108Part 3 · Repeat while true§4.3 Sentinel

A sentinel ends input without becoming data.

Here, 0 means “stop”; it is not one of the measurements.

System.out.print("Value (0 to stop): ");
int value = input.nextInt();

while (value != 0) {
   total += value;
   count++;
   value = input.nextInt();
}
5process7process2process0exit

Read → test → process → read again. The second read is the progress step.

A sentinel controls the loop; it does not belong in the total or count.§4.3

Part 4 · Count deliberately

for puts the counting rule in one line.

initializeint i = 0;continue whilei < 5;updatei++
for (int i = 0; i < 5; i++) {
   System.out.println(i);
}

Execution order: initialize once → test → body → update → test again.

The update runs after the body, before the next condition check.§4.4

ICS 108Part 4 · Count deliberatelyLoop choice

Choose the loop from what is known before it starts.

Known count

Use for

Process 10 scores. Visit every character. Repeat once per row.

Unknown count

Use while

Read until 0. Retry while invalid. Continue until a state changes.

counting rule togetherfor (int i = 0; i < n; i++)
condition-led rulewhile (value != sentinel)

Both can express repetition. Prefer the form that makes the stopping rule easiest to inspect.

Known iterations → for. Otherwise → while.§4.4

ICS 108Part 4 · Count deliberately§4.6 Strings

A string gives the loop its exact index range.

for (int i = 0; i < word.length(); i++) {
   char letter = word.charAt(i);
   System.out.println(i + ": " + letter);
}
0J1A2V3A4exit

Valid indices are 0 through length() - 1; therefore the condition uses i < word.length().

The data structure supplies the boundary.§4.6

Part 5 · Compose control flow

A loop selects the records. A branch classifies each one.

for (int i = 0; i < scoreCount; i++) {
   int score = input.nextInt();
   if (score >= 60) passed++;
   else failed++;
}
Outer loopWhich score now?

Repeat once per score.

Inner branchWhich category?

Increment exactly one counter.

Read the nesting from outside in: repeat this decision for every input.

Composition turns small control rules into useful programs.§§3.1, 4.4

ICS 108Part 5 · Compose control flow§4.7 Nested loops

The inner loop runs fully for each outer iteration.

for (int row = 1; row <= 2; row++) {
   for (int col = 1; col <= 3; col++) {
      System.out.print(row + "," + col + " ");
   }
}
1,11,21,32,12,22,3

2 outer iterations × 3 inner iterations = 6 executions of the inner body.

Trace the inner variable fastest.§4.7
ICS 108Part 5 · Compose control flow§4.10 Scope

A variable exists only inside its declaring block.

int total = 0;

for (int i = 0; i < 3; i++) {
   int score = input.nextInt();
   total += score;
}

System.out.println(total);
// i and score do not exist here
totalDeclared outside; survives after the loop.iDeclared in the for header; scoped through the loop.scoreDeclared in the body; recreated each iteration.

Declare a variable in the smallest scope that still covers every place it is needed.

Scope controls visibility, not just lifetime.§4.10
