Problem 1

Methods are defined once

public class PrintHeading {
   public static void printHeading() {
      // The heading statements go here.
   }
   public static void main(String[] args) { ... }
}

A method definition gives a named body of statements. Put the helper inside the class, outside main. public allows access; static lets main call it without an object.

Problem 3

A primitive parameter gets a copy

Problem: add one to a score of 7 and identify which variable changes.

public static int addPoint(int score) { ... }

int score = 7;
int updated = addPoint(score);
main score7
helper scorecopy of 7
helper changes7 → 8

Rule: The two variables named score are separate. main’s score is still 7.

Problem 3 - ScoreUpdate.javaICS 108 · Lecture 6P3-C2

Problem 3

A local name stays in its block

public static int addPoint(int score) {
   int bonus = 1;
   score = score + bonus;
   return score;
}

Rule: bonus is local: its name is available from its declaration to this body’s closing brace. main cannot use it.
