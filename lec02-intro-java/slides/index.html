ICS 108Chapter 1Part 2 · Program foundations§1.3 Language history

Part 2 · Program foundations

A brief history from C to Java

1978

C

Kernighan and Ritchie’s book helped C become a dominant systems language.

1985

C++

Stroustrup extended C with object-oriented programming. “++” suggests an improvement.

1991 → 1995

Java

James Gosling’s team at Sun began Java in 1991; its first public release came in 1995.

Java kept familiar C/C++-style syntax and used a virtual machine to help the same program run on different systems.

Java and JavaScript are different languages.

A language gives us the notation. A program is one specific solution written in that notation.

ICS 108Chapter 1Part 2 · Program foundations§1.6 Programs

Program vs. programming language

Program

A specific sequence of instructions that tells a computer how to perform a task.

Example: a program that calculates weekly pay.

Programming language

A defined vocabulary and grammar used to write programs.

Examples: Java, Python, and C++.

Relationship: Java is the language; Salary.java is one program written in Java.

Before writing that program, we first decide the exact steps it should perform.

ICS 108Chapter 1Part 2 · Program foundations§1.6 Algorithms

What is an algorithm?

An algorithm is a precise sequence of steps that solves a problem.

Problem→Algorithm→Java program→Execution

Example · Area of a triangle

  1. Input: base = 8, height = 5
  2. Process: area = 0.5 × base × height
  3. Output: area = 20

Java needs places to store the input and intermediate results. Those places are variables.

An algorithm is language-independent; code expresses it in a language.
ICS 108Chapter 1Part 3 · Java basics§1.7 Variables

Part 3 · Java basics

Variables in Java

A variable is a named place in memory that stores a value that may change.

int wage;Declare: create an integer variable named wage.

wage = 20;Assign: store 20 in that variable.

wage * 40 * 52Use: read the stored value in a calculation.

wage20

= means assignment: put the value on the right into the variable on the left.

A variable can receive a fixed value from the code, or it can receive a value typed by the user.

Type → name → stored value
ICS 108Chapter 1Part 3 · Java basics§1.7 Input

Input in Java

Input lets a program receive data while it is running. Java can read keyboard input with a Scanner.

import java.util.Scanner;

Scanner scnr = new Scanner(System.in);

int wage;
wage = scnr.nextInt();
  1. Make the Scanner class available.
  2. Connect a scanner named scnr to keyboard input.
  3. Declare the variable that will store the input.
  4. nextInt() reads one integer and assigns it to wage.
User types 20→nextInt()→wage stores 20

Once the program stores a value, it can calculate with it and display a result.

nextInt() reads an integer; nextLine() reads a line of text.

Output in Java

Output communicates a result to the user.

System.out.print("Salary is ");prints text and stays on the same line

System.out.println(wage);prints the variable’s value, then starts a new line

System.out.println("Wage is: " + wage);+ joins text and a value

Console 
Salary is 20
Wage is: 20

Text inside quotes is a string literal. A variable name without quotes prints its stored value.

We can now connect input, calculation, and output in one complete program.

print: same line · println: add newline
ICS 108Chapter 1Part 3 · Java basics§1.7 Complete example

Complete input–process–output example

Goal: read an hourly wage and estimate annual salary using 40 hours × 52 weeks.

import java.util.Scanner;

public class Salary {
  public static void main(String[] args) {
    Scanner scnr = new Scanner(System.in);
    int wage;

    wage = scnr.nextInt();             // input
    int salary = wage * 40 * 52;    // process
    System.out.println("Salary is " + salary); // output
  }
}

Inputwage = 20

Process20 × 40 × 52

OutputSalary is 41600

The computer ignores explanations written as comments, but those comments help a human follow the program.

Try another whole-number wage.
ICS 108Chapter 1Part 4 · Writing and fixing Java§1.8 Comments

Part 4 · Writing and fixing Java

Comments in Java

A comment explains code to people. The Java compiler ignores it.

  • // starts a single-line comment.
  • /* and */ surround a block comment.
  • Useful comments explain purpose or a non-obvious decision.
// Convert an hourly wage to an annual estimate.
int salary = wage * 40 * 52;

/* This estimate assumes
   40 hours for 52 weeks. */

The comments explain the assumption; the code performs the calculation.

Comments add explanation. Whitespace adds visual structure.

Comments are for readers, not for execution.
ICS 108Chapter 1Part 4 · Writing and fixing Java§1.8 Whitespace

Whitespace in Java

Whitespace means spaces, tabs, and newlines. Java ignores most whitespace between code elements.

Hard to read

if(wage>0){salary=wage*40*52;
System.out.println(salary);}

Same meaning, clearer structure

if (wage > 0) {
  salary = wage * 40 * 52;
  System.out.println(salary);
}
  • Indent code inside braces and use newlines to separate steps.
  • Whitespace inside a string is output, so it is not ignored: "Salary is ".

Readable formatting helps us notice mistakes—but we still need to understand the types of mistakes Java reports.

Whitespace usually changes readability, not behavior.
ICS 108Chapter 1Part 4 · Writing and fixing Java§1.10 Errors and warnings

Errors and warnings in Java

Syntax error

Breaks Java’s grammar. The compiler normally stops and reports an error.

int wage

Logic error

The program runs, but the algorithm or calculation produces the wrong result.

wage * 40 * 50

Runtime error

The program compiles, then fails while it is executing.

10 / 0

Warning

The compiler sees a possible problem. It usually still creates the executable program.

javac -Xlint File.java

Practical workflow: compile and run after a few statements, fix the first compiler error, then compile again.

Do not ignore warnings; investigate why they appear.

A reported line may be near the cause, not exactly at it.

ICS 108Chapter 1Part 4 · Writing and fixing Java§1.12 IDEs

Integrated development environments (IDEs)

An IDE is software that integrates the tools needed to develop programs.

  • Editor: write code with syntax highlighting and automatic indentation.
  • Build tools: compile and run with a command or shortcut.
  • Console: display program input, output, and compiler messages.
  • Debugger: pause execution and inspect values.

ICS 108Chapter 1Part 5 · Applied example§1.11 Married-couple names

Part 5 · Applied example

Married-couple names: problem and algorithm

Given Pat Smith and Kelly Jones, display five possible married-couple names, with Pat listed first.

  1. 1

    Read four strings: Pat’s first and last name, then Kelly’s first and last name.

  2. 2

    Print both original full names.

  3. 3

    Print both first names followed by Smith, then by Jones.

  4. 4

    Print the hyphenated options Smith-Jones and Jones-Smith.

Now we translate that algorithm into Java input, string combination, and output.

Inputs → combination rules → five output lines
