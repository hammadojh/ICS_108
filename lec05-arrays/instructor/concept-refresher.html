Arrays: storage, indexes, and safe loops.

Lecture abstract

An array stores a fixed number of values of one type. The array variable names the array, an index selects one value, and a loop visits the indexes. This lecture uses three small programs: Problem 1 introduces storage and direct access, Problem 2 fills an array and totals its values, and Problem 3 finds a maximum value and its index. The main safety rule is that an array of length N has valid indexes 0 through N − 1.

All problems§5.2 · PDF pp. 7–10

An array variable holds a reference to an allocated array

int[] temperatures declares an array reference variable. In Problem 1, braces create the array and supply its values. In Problem 2, new int[5] allocates five int elements before input fills them.

Key rule

The reference and the allocated array are related, but they are not the same thing.

Expand declaration, allocation, and memory meaning

Separate statements

int[] temperatures;
temperatures = new int[5];

The first line creates the reference variable. The second line creates the five-element array and assigns its reference to temperatures.

Combined statement

int[] temperatures = new int[5];

Problem 2 uses this form because it knows the required size before reading input. The allocated array keeps length 5. The variable may later receive a reference to another array.

Useful teaching sentence

“The variable gives us the array; new creates the element storage.”

Problem 1§§5.1–5.2 · PDF pp. 1–14

An index selects one element

An element is one stored value. Its index is the integer position inside brackets. Java starts array indexes at 0, so the five temperatures in Problem 1 use indexes 0, 1, 2, 3, and 4.

Key rule

For an array of length N, the valid index range is 0 through N - 1.

Expand zero-based positions and valid ranges 
int[] temperatures = {23, 25, 24, 22, 26};

temperatures[0] = 23;  // first element
temperatures[1] = 25;  // second element
temperatures[3] = 22;  // fourth element
temperatures[4] = 26;  // fifth and last element
Human positionArray indexAccess
first0temperatures[0]
second1temperatures[1]
fifth and last4temperatures[4]

Keep the two numbers separate: length 5 is a count, while index 4 is a position. If a user chooses “Day 1,” the matching index is 1 - 1, which is 0.

Useful teaching sentence

“Length tells us how many; index tells us which one.”

03

All problems§5.2 · PDF pp. 8–16

Arrays have starting values, direct access, and a length

new int[4] starts four integer elements at the default value 0. A brace initializer supplies explicit starting values and infers the length. Bracket access reads or updates one element. The property .length reports the element count.

Key rule

Use brackets for an element and .length for the count. Java arrays use length, not length().

Expand default values, initializer syntax, reads, and updates

Default values

int[] counts = new int[3];
// values: 0, 0, 0

double[] rates = new double[2];
// values: 0.0, 0.0

boolean[] flags = new boolean[2];
// values: false, false

Explicit starting values

int[] temperatures = {23, 25, 24, 22, 26};

int first = temperatures[0]; // read 23
temperatures[3] = 27;         // update 22 to 27

int count = temperatures.length; // 5
int last = temperatures[temperatures.length - 1]; // 26

Brackets [] appear in the type and in element access. Braces {} hold an initializer list. Do not use the two symbols as if they had the same job.

Useful teaching sentence

“Read the right side first, then store the result in the indexed element on the left.”

The standard indexed loop visits every valid element once

The loop index begins at 0 and increases by 1. The condition i < values.length allows the last valid index, length - 1, and stops before the invalid index length.

Key rule

Use for (int i = 0; i < array.length; ++i) as the standard forward traversal.

Expand the loop pattern and a complete trace 
for (int i = 0; i < values.length; ++i) {
    System.out.println(values[i]);
}
LengthIndexes used by the bodyFirst exit value
40, 1, 2, 3i == 4
10i == 1
0nonei == 0

The loop variable i has two jobs: it counts iterations and selects the current element. The body must use the same valid range as the array.

Do not use: i <= values.length. Its final body execution tries values[values.length].
Useful teaching sentence

“Start at the first valid index and stop at the first invalid index.”

Problem 2§§5.2, 5.4 · PDF pp. 14–25

Fill the array, then total its elements

A fill loop stores one input value in each element. A later processing loop reads those elements. The total accumulator starts at 0 before the processing loop and adds the current element during every iteration.

Key rule

Initialize the accumulator once before the loop. Inside the loop, update it with total += temperatures[i].

Expand the Problem 2 sequence and accumulator trace 
int[] temperatures = new int[5];

// Fill one element per iteration.
for (int i = 0; i < temperatures.length; i++) {
    temperatures[i] = input.nextInt();
}

// Add every stored element.
int total = 0;
for (int i = 0; i < temperatures.length; i++) {
    total += temperatures[i];
}

System.out.println("Total: " + total);

The accumulator belongs outside the loop because its previous result must remain available for the next iteration. Setting total = 0 inside the loop would erase the earlier work.

Useful teaching sentence

“The index chooses the current value; the accumulator remembers the values already processed.”

Problem 3§§5.3–5.4 · PDF pp. 20–24

The maximum value and its index must stay paired

Start highest from the first element, not from 0. When a larger temperature is found, update both highest and highestIndex in the same branch. This code needs at least one element because it reads element 0 before the loop.

Key rule

Keep this true: highest is stored at highestIndex among the elements processed so far.

Expand the Problem 3 code, empty-array requirement, and equal maximum values 
int[] temperatures = {-3, -7, -1, -5, -4};

// This code needs at least one element.
int highest = temperatures[0];
int highestIndex = 0;

for (int i = 1; i < temperatures.length; i++) {
    if (temperatures[i] > highest) {
        highest = temperatures[i];
        highestIndex = i;
    }
}

System.out.println("Highest temperature: " + highest);
System.out.println("Day: " + (highestIndex + 1));
  1. Initialization makes value and index refer to the same real element.
  2. The loop starts at index 1 because index 0 is already the current maximum.
  3. A larger value replaces both pieces of stored information.
  4. The strict operator > keeps the first index when the maximum appears more than once.

Starting with 0 fails for an all-negative array. For example, the maximum of −8, −2, and −5 is −2, not 0.

Empty-array check: If an empty array is possible, test temperatures.length == 0 before reading temperatures[0].
Useful teaching sentence

“When the best value changes, update the location at the same time.”

Debug the first invalid index and keep deferred topics separate

An index below 0 or at least equal to the array length is out of range. Java reports the access as a runtime exception. Use the array length, the current index, and a short trace to find the first invalid access. More advanced array structures are not part of the three problems in this lecture.

Key rule

For every array access, verify 0 <= index && index < array.length.

Expand the debugging procedure and deferred-topic list

Debugging procedure

  1. Read the array length from the declaration or .length.
  2. Write the valid range: 0 through length - 1.
  3. Find the expression inside each pair of access brackets.
  4. Trace the first and last loop iterations.
  5. Correct the index expression or loop boundary, then rerun the same input.
int[] values = new int[4];

values[3] = 10;  // valid: last index
values[4] = 20;  // invalid: index equals length
