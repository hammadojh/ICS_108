# Notice and source boundaries

This repository contains supplementary ICS 108 teaching material created for a Java foundations lesson on variables, expressions, data types, input, and debugging.

## Assigned course source

The package is aligned to zyBooks Chapter 2, sections 2.1–2.27, with selected coverage documented in `docs/CONTENT_MAP.md`.

zyBooks/Wiley source content is licensed separately and is not distributed in this repository. Students should use an institution-authorized zyBooks subscription or LMS link. The local `private-source/` directory is ignored by Git so an authorized instructor copy cannot be committed accidentally.

## Original teaching additions

The package adds its own instructional organization and examples, including:

- an interactive seconds converter;
- a grouping visualization for quotient and remainder;
- a predict-and-test circle debugging interaction;
- a `long`-based HealthData extension;
- six complete runnable Java examples; and
- six problem–prediction–demo–concept walkthroughs.
