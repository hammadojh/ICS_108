01

Learning outcomes

What you should be able to do

  1. Trace

    Follow variable assignments in execution order and explain why copied primitive values remain independent.

  2. Evaluate

    Apply grouping, precedence, integer division, modulo, and casts to predict an expression’s value.

  3. Choose

    Select int, long, double, char, or String from the meaning and range of a value.

  4. Read

    Use the appropriate Scanner method and reason about the input that remains after each read.

  5. Debug

    Distinguish compile-time, runtime, and logic errors with a predict-and-test workflow.
