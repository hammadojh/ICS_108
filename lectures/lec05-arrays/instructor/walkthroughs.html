public class TemperatureBasics {
   public static void main(String[] args) {
      // P1-C1: An array stores several elements of one type.
      // P1-C2: Declare and initialize five int elements.
      int[] temperatures = {23, 25, 24, 22, 26};

      // P1-C3: Index 0 is the first position.
      // P1-C4: Read the value stored at index 0.
      System.out.println("First day: " + temperatures[0]);

      // P1-C5: Replace the value stored at index 3.
      temperatures[3] = 27;
      System.out.println("Corrected fourth day: " + temperatures[3]);

      // P1-C6: length is 5; the last index is length - 1.
      System.out.println("Days stored: " + temperatures.length);
      System.out.println("Last day: "
            + temperatures[temperatures.length - 1]);
   }
}

Elaborated concepts for instructor reference

P1-C1 Array and element

An array is one fixed-size object that stores several values of the same type. Each stored value is an element.

Say: “One name gives us access to five related values.”

P1-C2 Declaration and initializer

int[] is the type. The braces create the array and supply its five starting values in order.

P1-C3 Zero-based index

Java numbers positions from 0. The first index is 0, the fourth is 3, and the valid range here is 0 through 4.

P1-C4 Read an element

temperatures[0] evaluates to 23. Reading an element does not remove or change it.

P1-C5 Update an element

temperatures[3] = 27; replaces only the old value at index 3. The other elements stay unchanged.

P1-C6 Length and last index

length is the number of elements, so the last valid index is length - 1. Index length is outside the array and fails at runtime.

import java.util.Scanner;

public class TemperatureTotal {
   public static void main(String[] args) {
      Scanner input = new Scanner(System.in);

      // P2-C1: Allocate five int elements; each starts at 0.
      int[] temperatures = new int[5];

      System.out.println("Enter 5 temperatures:");
      // P2-C2: Visit indexes 0 through length - 1.
      for (int i = 0; i < temperatures.length; i++) {
         // P2-C3: Store one input value in the current element.
         temperatures[i] = input.nextInt();
      }

      // P2-C5: Start the running total at 0.
      int total = 0;
      // P2-C4: Traverse the stored values a second time.
      for (int i = 0; i < temperatures.length; i++) {
         total += temperatures[i];
      }

      System.out.println("Total: " + total);
   }
}

Elaborated concepts for instructor reference

P2-C1 Allocation and defaults

new int[5] creates five integer elements. Java initializes every new int element to 0; the length cannot change later.

P2-C2 Indexed loop

The loop starts at index 0, continues while i < length, and increases i by one. That visits every valid index exactly once.

P2-C3 Fill the array

Each input value is stored in temperatures[i]. After five iterations, the array keeps all five values for later work.

P2-C4 Second traversal

The second loop reads values already stored by the first loop. Keeping input and calculation separate makes both jobs easy to trace.

P2-C5 Accumulator

total starts at 0. After each iteration, it equals the sum of every element visited so far.

Problem 3 · Search · About 11 minutes

Find the highest temperature and its day

Keep the best value and the index where that value was found.

Supporting slides 18–23Final check: slide 24.

Problem description

Given five negative temperatures, find the highest value and the day where it occurs. Day numbers shown to the user start at 1, while array indexes start at 0.

Starting data: {-3, -7, -1, -5, -4}. There is no keyboard input.

ConsoleExpected output
Highest temperature: -1
Day: 3

What new concepts does it have?

Students will learnSearch an array by keeping the best value and its matching index, including when every value is negative.

  • P3-C1First candidate
  • P3-C2Start at index 1
  • P3-C3Compare and update
  • P3-C4Keep the paired index
  • P3-C5Why all-negative works

public class HighestTemperature {
   public static void main(String[] args) {
      int[] temperatures = {-3, -7, -1, -5, -4};

      int highest = temperatures[0];
      int highestIndex = 0;

      // Add the search loop here.

      System.out.println("Highest temperature: " + highest);
      System.out.println("Day: " + (highestIndex + 1));
   }
}
public class HighestTemperature {
   public static void main(String[] args) {
      int[] temperatures = {-3, -7, -1, -5, -4};

      // P3-C1: Use the first element as the first candidate.
      // P3-C5: A real element works even when all values are negative.
      int highest = temperatures[0];

      // P3-C4: Keep the index paired with the highest value.
      int highestIndex = 0;

      // P3-C2: Index 0 is handled, so start at index 1.
      for (int i = 1; i < temperatures.length; i++) {
         // P3-C3: Replace the candidate only with a higher value.
         if (temperatures[i] > highest) {
            highest = temperatures[i];
            highestIndex = i;
         }
      }

      System.out.println("Highest temperature: " + highest);
      System.out.println("Day: " + (highestIndex + 1));
   }
}

Elaborated concepts for instructor reference

P3-C1 First candidate

Initialize highest with the first array element. The candidate is therefore always a value that actually appears in the data.

P3-C2 Start at index 1

Index 0 is already the candidate, so comparing it with itself adds no information. Begin the loop at 1.

P3-C3 Compare and update

Compare the current element with highest. Update only when the current value is larger; otherwise keep the existing candidate.

P3-C4 Keep the paired index

Whenever highest changes, update highestIndex in the same branch. Display highestIndex + 1 because people call index 2 “Day 3.”

P3-C5 Why all-negative works

Starting at 0 would invent a value larger than every temperature here. Starting with -3 lets the algorithm correctly replace it with -1.

Common mistake: set highest = 0. Rerun the same negative data and show why the printed result is not in the array.
