Problem 1

Application lifecycle

Application supplies the lifecycle of a JavaFX program.

Booking example

public class CampusBooking extends Application {
  @Override
  public void start(Stage stage) { /* GUI setup */ }
}

Another context

public class Attendance extends Application {
  @Override
  public void start(Stage stage) { /* GUI setup */ }
}

What stays the same: Call launch once; JavaFX calls your overridden start method.

Problem 1

Stage

A Stage is a top-level window.

Booking example

stage.setTitle("Campus booking");
stage.show();

Another context

stage.setTitle("Attendance");
stage.show();

What stays the same: Assign the title and scene, then call show to display the window.

Problem 1

Scene

A Scene holds the content displayed inside a Stage.

Booking example

Scene scene = new Scene(pane);
stage.setScene(scene);

Another context

Scene scene = new Scene(attendancePane);
stage.setScene(scene);

What stays the same: Give the scene a root node, then attach the scene to a Stage.

Problem 1

Pane and children

A Pane is a container whose children are graphical nodes.

Booking example

Pane pane = new Pane();
pane.getChildren().add(summary);

Another context

Pane pane = new Pane();
pane.getChildren().add(attendanceField);

What stays the same: Create a control, then add it to the displayed container.

Problem 1

TextField

A TextField displays one line of text and can allow editing.

Booking example

TextField summary = new TextField("3 seats: 30 SAR");
summary.setEditable(false);

Another context

TextField status = new TextField("Present: 18");
status.setEditable(false);

What stays the same: Use setText for its content and setEditable(false) for output-only text.

Label

A Label displays descriptive, non-editable text beside a control.

Booking example

Label seatsLabel = new Label("Seats:");

Another context

Label roomLabel = new Label("Room:");
roomLabel.setText("Room number:");

What stays the same: Use labels to explain what each value means.

Problem 2

GridPane coordinates

A GridPane places controls in cells addressed by column and row.

Booking example

grid.add(seatsLabel, 0, 0);
grid.add(seatsField, 1, 0);

Another context

grid.add(roomLabel, 0, 1);
grid.add(roomField, 1, 1);

What stays the same: The order is node, column, row; the top-left cell is (0, 0).

Number-to-text conversion

Integer.toString converts an int value into String text.

Booking example

int total = 3 * 10;
totalField.setText(Integer.toString(total));

Problem 3

Outer padding

Insets describes space at the top, right, bottom, and left edges of a region.

Booking example

grid.setPadding(new Insets(16));

Another context

grid.setPadding(new Insets(10, 20, 10, 20));

What stays the same: Apply Insets to the grid to keep content away from its edges.

Problem 3 - CampusBooking.javaICS 108 · Lecture 16P3-C2

Problem 3

Grid gaps

Horizontal and vertical gaps separate adjacent GridPane columns and rows.

Booking example

grid.setHgap(12);
grid.setVgap(8);

Another context

grid.setHgap(0);
grid.setVgap(16);

What stays the same: Hgap separates columns; Vgap separates rows.
