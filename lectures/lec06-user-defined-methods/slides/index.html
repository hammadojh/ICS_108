Problem 1 - CampusMenu.javaICS 108 · Lecture 6P1-C1

Problem 1

Methods are defined once

The café shows the same menu before an order and again for the next order.

public class CampusMenu {
   public static void printMenu() {
      // The two menu statements belong here.
   }
   public static void main(String[] args) { ... }
}

A method definition gives a named body of statements. The helper belongs inside the class, outside main. public allows access; static permits the call without an object.

Arguments match parameters by position

Lunch costs 12 SAR per sandwich and 5 SAR per juice. The method receives the quantities.

public static int calculateTotal(
      int sandwiches, int juices)

calculateTotal(1, 1)
Argument 1 → sandwiches1
Argument 2 → juices1

Problem 3 - WalletTopUp.javaICS 108 · Lecture 6P3-C1

Problem 3

A primitive parameter gets a copy

Your wallet holds 20 SAR. Previewing a 10 SAR top-up should leave the current balance unchanged.

public static int previewTopUp(int balance) { ... }

int balance = 20;
int previewBalance = previewTopUp(balance);
main balance20
Copied parameter20
Returned preview30

Rule: The helper changes its copy. main’s balance remains 20 until confirmation.

Problem 3 - WalletTopUp.javaICS 108 · Lecture 6P3-C2

Problem 3

A local name stays in its block

public static int previewTopUp(int balance) {
   int topUp = 10;
   balance = balance + topUp;
   return balance;
}

Rule: topUp is local to this method body. Its name is available from its declaration to the closing brace, and main cannot use it.
