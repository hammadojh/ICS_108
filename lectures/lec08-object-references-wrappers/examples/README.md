# Lecture 8 Java examples

Each file is a complete, independently runnable snapshot. Problems 2 and 3 extend the wallet from the preceding file. All three compile together; the numbered names do not indicate inheritance. No keyboard input is required.

From this folder:

```sh
javac CampusWallet8A.java CampusWallet8B.java CampusWallet8C.java
java CampusWallet8A
java CampusWallet8B
java CampusWallet8C
```

Expected output is in [student-problems.md](../student-problems.md).
