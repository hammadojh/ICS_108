# Lecture 8 Java examples

Each problem has its own `CampusWallet.java` in a separate folder. Problems 2 and 3 extend the preceding wallet; each folder is a complete program snapshot. No keyboard input is required.

To run a version, open its folder in your IDE, or use a terminal from this `examples` folder:

```sh
cd problem-1
javac CampusWallet.java
java CampusWallet
```

For the next version, return to `examples` and open `problem-2` or `problem-3`, then run the same `javac` and `java` commands. Compile and run each problem from its own folder because all three snapshots use the same class name.

Expected output is in [student-problems.md](../student-problems.md).
