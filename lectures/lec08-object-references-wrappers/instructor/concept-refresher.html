Object references and wrappers

Lecture abstract

The campus wallet now has two ways to begin, can transfer between objects, and can hold an optional reward. Constructor arguments select an overload. Reference variables can share one object; primitive arguments are copied. Integer is a wrapper reference type that can be null, and Java converts between Integer and int automatically. These three extensions continue the class and object work from Lecture 7.

Problem 1 · P1-C1zyBooks §7.7, pp. 36–43

Constructor overloading

A class can declare multiple constructors when their parameter lists differ. In this program: public CampusWallet8A()

Key rule

A class can declare multiple constructors when their parameter lists differ.

Expand explanation, trace, and common error

How it works and when it matters

The two constructors have the same class name, no return type, and different parameters. A return type alone cannot distinguish overloads. Keep both forms so the previous wallet operations still work.

Misconception and recovery

If the no-argument constructor is removed, new CampusWallet8A() fails to compile. Restore it and rebuild.

Useful teaching sentence

A class can declare multiple constructors when their parameter lists differ.

02

Problem 1 · P1-C2zyBooks §7.7, pp. 39–43; §7.9, pp. 47–54

Constructor chaining

this(...) calls another constructor in the same class and must be its first statement. In this program: this(20);

Key rule

this(...) calls another constructor in the same class and must be its first statement.

Expand explanation, trace, and common error

How it works and when it matters

The no-argument constructor delegates to the int constructor. The latter performs the field assignment once. this(20) invokes a constructor; this.balance selects a field.

Misconception and recovery

Putting any statement before this(20) fails to compile. Move the delegation to the first statement.

Useful teaching sentence

this(...) calls another constructor in the same class and must be its first statement.

03

Problem 1 · P1-C3zyBooks §7.7, pp. 36–43

Constructor selection

The arguments in a new expression determine which matching constructor runs. In this program: new CampusWallet8A(50)

Key rule

The arguments in a new expression determine which matching constructor runs.

Expand explanation, trace, and common error

How it works and when it matters

No arguments select the standard wallet constructor. One int selects the custom-balance constructor. Java chooses by parameter types and count, not the assignment variable name.

Misconception and recovery

Changing 50 to a String has no matching constructor. Supply an int or define an appropriate overload.

Useful teaching sentence

The arguments in a new expression determine which matching constructor runs.

04

Problem 2 · P2-C1zyBooks §7.8, pp. 43–47

Aliasing

Two reference variables can refer to the same object. In this program: CampusWallet8B alias = custom;

Key rule

Two reference variables can refer to the same object.

Expand explanation, trace, and common error

How it works and when it matters

alias and custom refer to one wallet, so either name sees its changed balance. Assigning the reference does not make a second wallet. A second new expression would.

Misconception and recovery

If alias is created with new, the two balances can diverge. Assign the existing reference to demonstrate sharing.

Useful teaching sentence

Two reference variables can refer to the same object.

05

Problem 2 · P2-C2zyBooks §7.10, pp. 54–61; §7.15, pp. 96–106

Primitive values

An int variable holds a number directly; assigning or passing it copies that value. In this program: int amount = 10;

Key rule

An int variable holds a number directly; assigning or passing it copies that value.

Expand explanation, trace, and common error

How it works and when it matters

The caller amount remains 10. Inside transferTo, the int parameter gets its own copy; setting it to 0 does not change the caller variable. The copied value can still be used to change object fields.

Misconception and recovery

Do not claim the transfer changed the caller amount. Print it after the call to check.

Useful teaching sentence

An int variable holds a number directly; assigning or passing it copies that value.

06

Problem 2 · P2-C3zyBooks §7.15, pp. 96–106

Reference parameters

A method receives a copy of an object reference, so it can use the same object. In this program: transferTo(CampusWallet8B recipient, int amount)

Key rule

A method receives a copy of an object reference, so it can use the same object.

Expand explanation, trace, and common error

How it works and when it matters

The recipient parameter is a local reference to the standard wallet. Calling recipient.addMoney changes that object. Java passes values: the value of a reference variable is copied, rather than an object being passed by reference. Reassigning recipient would not rebind the caller variable.

Misconception and recovery

If transferTo creates a new recipient instead of using the argument, the standard wallet remains at 20. Use the passed reference.

Useful teaching sentence

A method receives a copy of an object reference, so it can use the same object.

07

Problem 3 · P3-C1zyBooks §7.10, pp. 54–61

Wrapper class

Integer is a reference type that represents an int value. In this program: Integer reward;

Key rule

Integer is a reference type that represents an int value.

Expand explanation, trace, and common error

How it works and when it matters

int holds a primitive value directly. Integer refers to an immutable wrapper object representing an int. A wrapper can be used where an object is required, such as a generic collection or an optional field. The reference can also be null.

Misconception and recovery

Do not use new Integer(...); constructors are deprecated in modern Java. Autoboxing or Integer.valueOf is preferable.

Useful teaching sentence

Integer is a reference type that represents an int value.

08

Problem 3 · P3-C2zyBooks §7.8, pp. 43–47; §7.10–7.11, pp. 54–67

null reference

null means a reference currently refers to no object. In this program: if (reward == null)

Key rule

null means a reference currently refers to no object.

Expand explanation, trace, and common error

How it works and when it matters

No reward differs from a reward of zero. The nullable Integer field starts as null, and clearing it returns to that state. Check null before arithmetic, because arithmetic would unbox the value.

Misconception and recovery

If reward is null and is unboxed, a NullPointerException occurs. Guard the use and return the base balance.

Useful teaching sentence

null means a reference currently refers to no object.

09

Problem 3 · P3-C3zyBooks §7.11, pp. 61–67

Unboxing

Unboxing converts a wrapper value to the corresponding primitive value. In this program: balance + reward

Key rule

Unboxing converts a wrapper value to the corresponding primitive value.

Expand explanation, trace, and common error

How it works and when it matters

The + operator needs numeric values; Java unboxes reward to int after the null check. The expression computes a new int and leaves the Integer object unchanged. Wrapper objects are immutable.

Misconception and recovery

Moving balance + reward before the null check can crash when there is no reward.

Useful teaching sentence

Unboxing converts a wrapper value to the corresponding primitive value.

10

Problem 3 · P3-C4zyBooks §7.11, pp. 61–67

Autoboxing

Autoboxing converts a primitive value to its matching wrapper type. In this program: standard.setReward(5);

Key rule

Autoboxing converts a primitive value to its matching wrapper type.

Expand explanation, trace, and common error

How it works and when it matters

The literal 5 is an int and setReward expects Integer, so Java boxes it automatically. The parameter receives a reference value. Clearing with null selects absence without pretending that the reward is zero.

Misconception and recovery

An Integer object should be compared by value with equals, not assumed equal by == identity. This example only compares to null.

Useful teaching sentence

Autoboxing converts a primitive value to its matching wrapper type.

Readiness check

Predict which constructor runs for each new expression. Explain why alias and custom print the same balance, but amount stays 10. Then predict the result of using reward in arithmetic before checking whether it is null.

Answers: arguments select the matching constructor; alias and custom share one wallet; the int parameter is a copy; unboxing null throws NullPointerException.
