Complete code

CampusBooking.javaComplete
import javafx.event.*;
import javafx.scene.control.*;
import javafx.application.Application;
import javafx.stage.Stage;
import javafx.scene.Scene;
import javafx.scene.layout.GridPane;
import javafx.geometry.Insets;
public class CampusBooking extends Application {
  private TextField input = new TextField("3");
  private TextField output = new TextField("30");
  @Override
  public void start(Stage stage) {
    TextField price = new TextField("10");
    output.setEditable(false);
    price.setEditable(false);
    GridPane grid = new GridPane();
    grid.setPadding(new Insets(16));
    grid.setHgap(12);
    grid.setVgap(8);
    grid.add(new Label("Seats:"), 0, 0);
    grid.add(input, 1, 0);
    grid.add(new Label("Total (SAR):"), 0, 1);
    grid.add(output, 1, 1);
    grid.add(new Label("Price per seat (SAR):"), 0, 2);
    grid.add(price, 1, 2);
    Button calc = new Button("Calculate");
    grid.add(calc, 1, 3);
    // P1-C2: Handle each button action.
    calc.setOnAction(new EventHandler<ActionEvent>() {
      @Override public void handle(ActionEvent event) {
        updateTotal();
      }
    });
    stage.setScene(new Scene(grid));
    stage.setTitle("Campus booking");
    stage.show();
  }
  private void updateTotal() {
    // P1-C1: Read current text.
    String text = input.getText();
    // P1-C3: Parse the seat count.
    int seats = Integer.parseInt(text);
    output.setText(Integer.toString(seats * 10));
  }
  public static void main(String[] args) { launch(args); }
}

Elaborated concepts for instructor reference

P1-C1 Reading editable text

Read the input inside the handler so each click uses the latest text.

Monday’s seats display becomes editable; the price and total fields remain output-only. The application waits for actions after start finishes. The same input field survives between clicks, while a local text variable is created for each handler execution.

Common mistakes: Do not calculate only in start and expect later edits to recalculate automatically.

Common mistake: Do not calculate only in start and expect later edits to recalculate automatically.

P1-C2 Button action handler

setOnAction registers the handler; handle runs later for each action.

The anonymous class creates an EventHandler object without declaring a separate class name. EventHandler<ActionEvent> means this handler accepts action events; handle is the required method. The outer }); closes the anonymous class, the method call, and its statement. Our examples use fields for shared controls and the updateTotal helper to keep the event template short.

Common mistakes: Do not confuse handler registration with handler execution.

Common mistake: Do not confuse handler registration with handler execution.

P1-C3 Parsing an integer

getText reads a String; parseInt performs the numeric conversion.

Problem 1 deliberately assumes integer inputs from 1 to 4; Problem 2 adds recovery. Empty text, nonnumeric text, and values outside the int range fail parsing. A parseable value such as 0 still needs a booking rule. trim removes surrounding whitespace when we introduce validation.

Common mistakes: Parsing successfully does not prove that a seat count is allowed.

Common mistake: Parsing successfully does not prove that a seat count is allowed.

Trace: start builds the form and registers the handler, then returns. A click runs handle; updateTotal reads the current text, parses the count, multiplies by 10, and updates the result.

Practice and answer: Try 1 then 3 with a click after each: totals 10 then 30. Typing without clicking leaves the previous total. Malformed input is outside this first version’s contract.

CampusBooking.javaComplete
import javafx.event.*;
import javafx.scene.control.*;
import javafx.application.Application;
import javafx.stage.Stage;
import javafx.scene.Scene;
import javafx.scene.layout.GridPane;
import javafx.geometry.Insets;
import javafx.scene.control.Alert.AlertType;
public class CampusBooking extends Application {
  private TextField input = new TextField("3");
  private TextField output = new TextField("30");
  @Override
  public void start(Stage stage) {
    TextField price = new TextField("10");
    output.setEditable(false);
    price.setEditable(false);
    GridPane grid = new GridPane();
    grid.setPadding(new Insets(16));
    grid.setHgap(12);
    grid.setVgap(8);
    grid.add(new Label("Seats:"), 0, 0);
    grid.add(input, 1, 0);
    grid.add(new Label("Total (SAR):"), 0, 1);
    grid.add(output, 1, 1);
    grid.add(new Label("Price per seat (SAR):"), 0, 2);
    grid.add(price, 1, 2);
    Button calc = new Button("Calculate");
    grid.add(calc, 1, 3);
    calc.setOnAction(new EventHandler<ActionEvent>() {
      @Override public void handle(ActionEvent event) {
        updateTotal();
      }
    });
    stage.setScene(new Scene(grid));
    stage.setTitle("Campus booking");
    stage.show();
  }
  private void updateTotal() {
    output.clear();
    try {
      // P2-C1: Parse, then check 1 to 4.
      int seats = Integer.parseInt(input.getText().trim());
      if (seats < 1 || seats > 4) {
        showError("Choose 1 to 4 seats.");
        return;
      }
      output.setText(Integer.toString(seats * 10));
    } catch (NumberFormatException e) {
      // P2-C3: Allow a later retry.
      showError("Enter a whole number.");
    }
  }
  private void showError(String message) {
    // P2-C2: Show error feedback.
    Alert alert = new Alert(AlertType.ERROR, message);
    alert.setTitle("Invalid booking");
    alert.setHeaderText(null);
    alert.showAndWait();
  }
  public static void main(String[] args) { launch(args); }
}

Elaborated concepts for instructor reference

P2-C1 Validation order

Parse first, then check the booking range before updating the total.

Trim first, parse inside try, test the range, then calculate. Clearing the old total before validation prevents an old successful total from looking like the result of the invalid input. Return exits only this helper call; the application remains open for correction.

Common mistakes: Do not use an old total as the apparent result for invalid new input.

Common mistake: Do not use an old total as the apparent result for invalid new input.

P2-C2 Error alerts

Use AlertType.ERROR for invalid input and showAndWait to display it.

The showError helper sets the title and removes the default header so the student sees one clear message. ERROR, INFORMATION, WARNING, CONFIRMATION, and NONE communicate different purposes. A confirmation decision requires inspecting the returned button choice; that is outside these problems. showAndWait pauses this call until dismissal while JavaFX continues processing UI events.

Common mistakes: An alert is feedback; it does not itself prevent invalid calculations.

Common mistake: An alert is feedback; it does not itself prevent invalid calculations.

P2-C3 Recovery inside an event

Catch NumberFormatException and finish this action without closing the window.

The exception is caused by the current text, not by the button itself. Keep the protected operation inside try. The catch shows a specific message and leaves the result blank. Replacing the input and clicking again is the GUI equivalent of retrying the console input loop.

Common mistakes: Do not catch every Exception when only integer-format failure is expected.

Common mistake: Do not catch every Exception when only integer-format failure is expected.

Trace: Clear the old result; trim and parse; reject an out-of-range value before multiplying; show the relevant alert; return to the same form. The next click starts a fresh attempt.

Practice and answer: Test empty text, 3.5, and 2147483648: format alert. Test -1 and 5: range alert. Test 1 and 4: totals 10 and 40. Dismiss an error, enter 3, click: total 30.

CampusBooking.javaComplete
import javafx.scene.image.*;
import javafx.event.*;
import javafx.scene.control.*;
import javafx.application.Application;
import javafx.stage.Stage;
import javafx.scene.Scene;
import javafx.scene.layout.GridPane;
import javafx.geometry.Insets;
import javafx.scene.control.Alert.AlertType;
import javafx.scene.input.MouseEvent;
public class CampusBooking extends Application {
  private TextField input = new TextField("3");
  private TextField output = new TextField("30");
  private int index = 0;
  private Image[] images;
  private ImageView view;
  @Override
  public void start(Stage stage) {
    TextField price = new TextField("10");
    output.setEditable(false);
    price.setEditable(false);
    GridPane grid = new GridPane();
    grid.setPadding(new Insets(16));
    grid.setHgap(12);
    grid.setVgap(8);
    grid.add(new Label("Seats:"), 0, 0);
    grid.add(input, 1, 0);
    grid.add(new Label("Total (SAR):"), 0, 1);
    grid.add(output, 1, 1);
    grid.add(new Label("Price per seat (SAR):"), 0, 2);
    grid.add(price, 1, 2);
    Button calc = new Button("Calculate");
    grid.add(calc, 1, 3);
    calc.setOnAction(new EventHandler<ActionEvent>() {
      @Override public void handle(ActionEvent event) {
        updateTotal();
      }
    });
    // P3-C1: Load and display images.
    images = new Image[] {
      new Image("file:venue-a.png"),
      new Image("file:venue-b.png")
    };
    view = new ImageView(images[0]);
    // P3-C2: Preserve proportions.
    view.setFitWidth(240);
    view.setPreserveRatio(true);
    grid.add(view, 1, 4);
    // P3-C3: Remember the image index.
    view.setOnMouseClicked(new EventHandler<MouseEvent>() {
      @Override public void handle(MouseEvent event) {
        index = (index + 1) % images.length;
        view.setImage(images[index]);
      }
    });
    stage.setScene(new Scene(grid));
    stage.setTitle("Campus booking");
    stage.show();
  }
  private void updateTotal() {
    output.clear();
    try {
      // P2-C1: Parse, then check 1 to 4.
      int seats = Integer.parseInt(input.getText().trim());
      if (seats < 1 || seats > 4) {
        showError("Choose 1 to 4 seats.");
        return;
      }
      output.setText(Integer.toString(seats * 10));
    } catch (NumberFormatException e) {
      // P2-C3: Allow a later retry.
      showError("Enter a whole number.");
    }
  }
  private void showError(String message) {
    // P2-C2: Show error feedback.
    Alert alert = new Alert(AlertType.ERROR, message);
    alert.setTitle("Invalid booking");
    alert.setHeaderText(null);
    alert.showAndWait();
  }
  public static void main(String[] args) { launch(args); }
}

Elaborated concepts for instructor reference

P3-C1 Image and ImageView

Load an Image, assign it to an ImageView, and add the view to the grid.

The PDF’s ImageViewer task gives the behavior but omits its solution. This original extension loads two supplied PNG venue diagrams from the working directory. A relative file URL is not relative to the Java source. Check isError when diagnosing a blank image; a failed image load can be recorded on the Image rather than reported as an input exception.

Common mistakes: A missing image or wrong working directory can produce a blank view.

Common mistake: A missing image or wrong working directory can produce a blank view.

P3-C2 Image display size

Set fitWidth and preserveRatio on the view, not on the source image.

The view fits within the booking form without stretching the diagram. We set only fitWidth; JavaFX derives height from the original ratio. Display scaling does not resize or overwrite the PNG file.

Common mistakes: Do not confuse displayed dimensions with the image file’s dimensions.

Common mistake: Do not confuse displayed dimensions with the image file’s dimensions.

P3-C3 Mouse clicks and persistent state

Store the image index in a field and wrap it after the last image.

setOnMouseClicked registers an EventHandler<MouseEvent>; JavaFX passes a mouse event to handle. Our anonymous handler updates the field and then the ImageView. The initialized, nonempty image array is a prerequisite for modulo cycling. Changing the view leaves the booking input and result untouched. This is browsing venues, not confirming a reservation.

Common mistakes: Do not reset the index inside the handler or use modulo with an empty array.

Common mistake: Do not reset the index inside the handler or use modulo with an empty array.

Trace: A click advances the stored index modulo 2 and changes the image. Calculation and validation still use the same fields.

Practice and answer: Click five times: venue B. Calculate 2 seats: 20. Try bad text, dismiss the alert, then calculate 4 seats: 40. Missing images: restore both PNGs and the working directory.
