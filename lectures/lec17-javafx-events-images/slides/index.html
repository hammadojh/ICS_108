Problem 1

Button action handler

An action handler is code JavaFX calls when a control fires an action event.

Booking example

calc.setOnAction(new EventHandler<ActionEvent>() {
  @Override public void handle(ActionEvent event) {
    updateTotal();
  }
});

Another context

save.setOnAction(new EventHandler<ActionEvent>() {
  @Override public void handle(ActionEvent event) {
    status.setText("Saved");
  }
});

What stays the same: setOnAction registers the handler; handle runs later for each action.

Problem 2

Validation order

Input validation checks both its text format and the permitted value range.

Booking example

int seats = Integer.parseInt(input.getText().trim());
if (seats < 1 || seats > 4) {
  showError("Choose 1 to 4 seats.");
  return;
}

Another context

int mark = Integer.parseInt("105");
if (mark < 0 || mark > 100) {
  System.out.println("Invalid mark");
}

What stays the same: Parse first, then check the booking range before updating the total.

Error alerts

An Alert is a dialog that reports information or asks for a response.

Booking example

Alert alert = new Alert(AlertType.ERROR, message);

Problem 2

Recovery inside an event

Catching an input exception inside a handler allows a later corrected action.

Booking example

try {
  int seats = Integer.parseInt(text);
} catch (NumberFormatException e) {
  showError("Enter a whole number.");
}

Another context

try {
  int mark = Integer.parseInt("absent");
} catch (NumberFormatException e) {
  System.out.println("No numeric mark");
}

What stays the same: Catch NumberFormatException and finish this action without closing the window.

Image and ImageView

Image holds image data; ImageView is the node that displays that data.

Booking example

Image image = new Image("file:venue-a.png");

ImageView badge = new ImageView(logo);

What stays the same: Load an Image, assign it to an ImageView, and add the view to the grid.

Image display size

ImageView can fit an image to a target width while preserving its aspect ratio.

Mouse clicks and persistent state

A mouse handler can update a field that remembers which image is selected.

Booking example

index = (index + 1) % images.length;
view.setImage(images[index]);

Check your understanding

Why should getText run inside the action handler, and why should the image index live outside it?

getText must read each new input at click time. The index must survive between clicks; a local index initialized inside handle would reset every time.
