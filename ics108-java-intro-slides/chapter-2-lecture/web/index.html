ICS 108Chapter 2Part 1 · Values and state§2.1 Variables and assignments

Variables remember current state

A variable is a named item that holds the program’s current value.

numPeople5

The bus starts with 5 people.

  1. Start: 5
  2. 3 get on
  3. 2 get off
  4. 4 get off
  5. 5 get on

The value changes over time because each assignment replaces the previous state.

Source activity: people on a bus, §2.1.
ICS 108Chapter 2Part 1 · Values and state§2.1 Assignment

Assignment is an action

= evaluates the right side, then stores that value in the variable on the left.

x = 5;→
x5y?

Store 5 in x.

y = x;→
x5y5

Read x; copy its current value into y.

x = 3;→
x3y5

Replace x. The earlier copy in y does not change.

The left side must be one variable. x + 1 = 3; is not a valid assignment.

Before Java can store a value, the program must declare the variable and its type.

Assignments only make sense in execution order.
ICS 108Chapter 2Part 1 · Values and state§2.2 Variables (int)

Declaring and initializing int variables

int stores whole numbers such as a count, age, or score.

Declare, then assign

int userAge;
userAge = 23;

Declaration creates a named integer location. Assignment stores the first value.

Declare and initialize

int maxScore = 100;

Initialization gives the variable a starting value in the declaration.

  • Declare a variable before reading or assigning it.
  • Assign a local variable before using its value; otherwise Java reports a compiler error.
  • The memory address exists, but its exact number is irrelevant to the programmer.

The type describes the value; the identifier should describe the value’s purpose.

int variableName = initialValue;
ICS 108Chapter 2Part 1 · Values and state§2.3 Identifiers

Identifiers in Java

An identifier is a programmer-created name for a variable, method, or other item.

Required rules

  • Use letters, digits, _, or $.
  • Do not start with a digit.
  • Do not use a reserved word such as int or class.
  • Capitalization matters: numCars and NumCars differ.

Java naming practice

Use meaningful lower camel case for variables.

numStudentspeopleOnBus3rdPlacevery tallint

Valid is not always clear. Prefer consistency and purpose.

Once a variable has a clear name, an assignment can update its current value.

Course convention: lower camel case for variables.

Updating a variable

The same variable may appear on both sides because the right side is evaluated before the new value is stored.

numPeople = 10;current value10
numPeople = numPeople + 5;read 10, calculate 15, overwrite15
numPeople += 5;compound shorthand for the same update20
+=add-=subtract*=multiply/=divide%=remainder

Use a compound operator only when the left-side variable is also the value being updated.

The calculation on an assignment’s right side is an expression.

x += 1; is shorthand for x = x + 1;

Part 2 · Expressions

Arithmetic expressions

An expression combines values and operators and evaluates to one value.

result = 2 * (x + 1);
literalvariableoperatorsparentheses
+ addition- subtraction / negation* multiplication/ division% remainder

If x is 4, then 2 * (x + 1) evaluates to 10; that value is assigned to result.

When an expression has several operators, Java follows precedence rules.

Expressions are values in progress.
ICS 108Chapter 2Part 2 · Expressions§2.4 Precedence

Operator precedence

Java evaluates parentheses first, then unary minus, then * / %, then + -. Equal-precedence operators run left to right.

Given

x = 4;
w = 2;
  1. 3 * (x + 10 / w)
  2. 3 * (4 + 5)10 / 2 first
  3. 3 * 9finish parentheses
  4. 27multiply

Use extra parentheses when they make the intended order obvious: 3 * (x + (10 / w)).

Division has the same precedence as multiplication—but its behavior also depends on operand types.

Spacing improves reading; it does not change precedence.
ICS 108Chapter 2Part 2 · Expressions§2.11 Integer division and modulo

Integer division and modulo

For non-negative integers, division gives the whole-number quotient and modulo gives the remainder.

17 / 53complete groups

17 % 52items left over

Integer operands: 7 / 2 → 3At least one double: 7 / 2.0 → 3.5

For integer / or %, a divisor of zero causes a runtime error.

Together, quotient and remainder can split a total into meaningful units.

/ answers “how many groups?” · % answers “what remains?”

ICS 108Chapter 2Part 2 · Expressions§§2.11-2.12 Common errors

Common integer-division traps

Unexpected

double area = (1 / 2) * base * height;

1 / 2 is integer division, so it becomes 0. The area is always zero.

Intended

double area = (1.0 / 2.0) * base * height;

A double operand causes floating-point division, so the factor is 0.5.

(double)(7 / 2)3.0too late: integer division already produced 3
(double) 7 / 23.5cast an operand before division

To choose the correct operation, first choose a type that matches the kind of value.

Cast before the operation whose behavior must change.
ICS 108Chapter 2Part 3 · Numeric types§2.7 int vs double

Part 3 · Numeric types

Choosing int or double

Choose the type from the meaning of the value—not from how you plan to display it.

int

Whole numbers for countable quantities.

  • 42 cars
  • 10 students
  • 365 days

double

Measurements or results that may contain a fraction.

  • 98.6 degrees
  • 400.5 miles
  • 3.5 children per family on average

Money note: floating-point rounding can be unsuitable for exact currency. Introductory programs may store cents as integers.

A double has its own input method and can be formatted when printed.

Count → usually int · Measurement → usually double
ICS 108Chapter 2Part 3 · Numeric types§2.7 Floating-point numbers

Floating-point input and output

double literals include a decimal point; nextDouble() reads a floating-point value.

double milesTravel;
double hoursDrive;

milesTravel = scnr.nextDouble();
hoursDrive = milesTravel / 60.0;

System.out.printf("%.2f hours\n", hoursDrive);
Console
Input: 400.5
Raw value: 6.675
Formatted: 6.68 hours
  • Write 0.5, not .5, for easy reading.
  • printf("%.2f", value) rounds displayed output to two decimal digits; the stored value does not change.
  • Floating-point division by zero produces Infinity or NaN in Java rather than an integer divide-by-zero exception.

When an expression mixes int and double, Java may convert a value automatically.

nextInt() for int · nextDouble() for double
ICS 108Chapter 2Part 3 · Numeric types§2.12 Type conversions

Type conversions and casts

A type conversion changes a value from one data type to another.

int numBirths = 316;→0.504 * numBirths→0.504 * 316.0→159.264

Implicit conversion

Java safely converts int to double when a floating-point operation requires it.

Explicit cast

(double) total / count requests floating-point division. (int) 9.8 truncates to 9.

// 175 / 2 becomes 87 first
double wrong = (double) ((90 + 85) / 2); → 87.0

// Cast before division
double right = (double) (90 + 85) / 2; → 87.5

Types control allowed values; constants control whether a value may change.

Automatic when safe · explicit when precision may change
ICS 108Chapter 2Part 3 · Numeric types§2.9 Constant variables

Constant variables

A constant variable is initialized once and cannot be assigned a new value.

final double SPEED_OF_SOUND = 761.207;
final double SECONDS_PER_HOUR = 3600.0;

timeInHours = secondsBetween / SECONDS_PER_HOUR;
distanceMiles = SPEED_OF_SOUND * timeInHours;

final lets the compiler reject accidental changes.

UPPER_SNAKE_CASE makes constants easy to recognize.

Names explain what a number means and reduce repeated “magic numbers.”

SPEED_OF_SOUND = 800.0; would be a compiler error after the constant is initialized.

Constants provide meaningful values; Java’s Math class provides reusable calculations.

final type NAME = value;

ICS 108Chapter 2Part 3 · Numeric types§§2.18-2.19 Overflow

Integer overflow and numeric range

Overflow occurs when a value is outside the range its type can store.

int

32 bits · about −2.1 billion to +2.1 billion

long

64 bits · much larger whole-number range

32 available bits00000000000000000000000000000001
4,294,967,297requires a 33rd bit

The extra bit is lost; a wrapped value may be stored instead of a clear error.

Overflow can occur during an intermediate calculation even when the final mathematical result would fit.

Numbers use numeric types; text uses character and string types.

Use long when an integer may exceed the int range.
ICS 108Chapter 2Part 4 · Text values§§2.16-2.17 Characters and strings

Part 4 · Text values

char and String

Java distinguishes one character from a sequence of characters.

char

Stores one character literal in single quotes.

char grade = 'A';
char newline = '\n';

String

Refers to a sequence of characters written in double quotes.

String courseName = "ICS 108";
String room = "Building 24";

'A' is a char; "A" is a one-character String. Their types differ.

Scanner provides different ways to read one token, one character, or a whole line.

Single quotes: one char · double quotes: String
ICS 108Chapter 2Part 4 · Text values§2.17 String input

Reading text with Scanner

next() reads one token; nextLine() reads the rest of a line.

Stored value

Choose a Scanner method.Whitespace determines where reading stops.
age = scnr.nextInt();
name = scnr.nextLine();

Common pitfall: nextInt() leaves the newline. The next nextLine() may read an empty remainder. Consume that newline before reading the intended line.

When output is wrong, inspect program state methodically instead of making random edits.

Character input: scnr.next().charAt(0)
ICS 108Chapter 2Part 5 · Integrating the concepts§2.22 Debugging

Part 5 · Integrating the concepts

Methodical debugging

Debugging is a repeated two-step process: predict a possible cause, then test whether the prediction is correct.

Observe the wrong result→Predict one cause→Run a focused test→Keep or reject the prediction↺

Given circumference = 10:

Observed radius: 15.71
Expected radius: about 1.59

Your diagnosis

Select the highlighted calculation.

Look for an order-of-operations problem.

Useful tests include printing intermediate values, temporarily assigning a known value, and commenting out unrelated code. Remove temporary debug statements afterward.

The final program uses those habits to connect variables, expressions, types, and output.

Do not stare and guess: predict, test, learn, repeat.

Complete example: HealthData

Read age in years, estimate days and minutes, then estimate lifetime heartbeats.

final int MINUTES_PER_DAY = 24 * 60;
final int BEATS_PER_MINUTE = 72;

int ageYears = scnr.nextInt();
int ageDays = (ageYears * DAYS_PER_YEAR)
    + (ageYears / 4);
long ageMinutes = (long) ageDays * MINUTES_PER_DAY;
long heartbeats = ageMinutes * BEATS_PER_MINUTE;
