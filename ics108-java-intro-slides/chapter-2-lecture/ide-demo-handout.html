Chapter 2 IDE Demo — Instructor Cue Sheet

Variables, expressions, integer division, modulo, and casts

Target time
10–12 minutes

Demo rhythm: type one small change, ask for a prediction, run, and trace the value. Keep the editor and Console visible together.

1. Trace assignment state · 2 minutes

  1. Create Chapter2Demo.java

    public class Chapter2Demo {
  public static void main(String[] args) {
    int x = 5;
    int y = x;
    x = 3;

    System.out.println("x = " + x);
    System.out.println("y = " + y);
  }
}

    Ask before running: “After x changes to 3, does y also change?”

    Expected: x = 3 and y = 5. Assignment copied the value that x held at that moment.

    Say: “= is an action: evaluate the right side, then overwrite the left-side variable.”

  2. Update a variable using its current value

    int numPeople = 10;
numPeople = numPeople + 5;
numPeople += 5;
System.out.println(numPeople);

    Ask: “What is printed after both updates?” Answer: 20.

2. Demonstrate integer division and modulo · 4 minutes

  1. Start with quotient and remainder

    int totalItems = 17;
System.out.println(totalItems / 5);
System.out.println(totalItems % 5);

    Expected: 3 complete groups and 2 remaining items.

  2. Convert total seconds

    int totalSeconds = 3672;
int hours = totalSeconds / 3600;
int afterHours = totalSeconds % 3600;
int minutes = afterHours / 60;
int seconds = afterHours % 60;

System.out.println(hours + ":" + minutes + ":" + seconds);

    Ask before running: “Which lines find complete units, and which lines keep the remainder?”

    Expected output: 1:1:12.

  3. Expose the type trap, then fix it

    double average = 7 / 2;
System.out.println(average);

    First output: 3.0. Integer division happens before assignment to double.

    double average = (double) 7 / 2;

    Corrected output: 3.5. Cast an operand before division.

Text Input, Debugging, and HealthData

Use focused tests and show intermediate values.

Target time
8–10 minutes

3. Show the Scanner newline pitfall · 2 minutes

Problem

int age = scnr.nextInt();
String fullName = scnr.nextLine();

System.out.println(fullName);

Say: nextInt() reads the number but leaves the newline. The next nextLine() may read only that empty remainder.

Fix

int age = scnr.nextInt();
scnr.nextLine(); // consume newline
String fullName = scnr.nextLine();

System.out.println(fullName);

Ask: “Why is the extra call not stored?” Answer: Its job is only to remove the leftover newline.

5. Complete HealthData demo · 4 minutes

final int DAYS_PER_YEAR = 365;
final int MINUTES_PER_DAY = 24 * 60;
final int BEATS_PER_MINUTE = 72;

int ageYears = scnr.nextInt();
int ageDays = (ageYears * DAYS_PER_YEAR) + (ageYears / 4);
long ageMinutes = (long) ageDays * MINUTES_PER_DAY;
long heartbeats = ageMinutes * BEATS_PER_MINUTE;

System.out.println("Days: " + ageDays);
System.out.println("Minutes: " + ageMinutes);
System.out.println("Heartbeats: " + heartbeats);

Input

19

Expected output

Days: 6939
Minutes: 9992160
Heartbeats: 719435520

Ask: “Why use constants, integer division, a cast, and long?”

  • Constants name assumptions and prevent accidental changes.
  • ageYears / 4 estimates complete leap years.
  • The cast makes the intermediate multiplication use long.
  • long prevents large heartbeat estimates from overflowing int.

Final instructor checklist

  • Increase editor and Console font size.
  • Run after each meaningful change.
  • Ask for a prediction before every run.
  • Keep the exact input visible.
  • Remove temporary debug statements.
  • If short on time, omit the Scanner pitfall.
