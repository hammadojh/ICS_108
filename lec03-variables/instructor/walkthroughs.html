1. Trace changing state

6 min / Source sections 2.1-2.3

Students will learn

Trace assignment state changes and explain why a copied value does not update with the original.

Problem

A bus starts with 5 people. Then 3 get on, 2 get off, 4 get off, and 5 get on. Store the original count separately. What should the two variables contain at the end?

Ask before typing

"Does copying numPeople make a live connection, or copy only its current value?"

Expected prediction

Final count 7; saved first count 5.

Type: StateTrace.javatrace each update

public class StateTrace {

    int firstCount = numPeople;

  }

public class StateTrace {
  public static void main(String[] args) {
    int numPeople = 5;
    int firstCount = numPeople;

    numPeople += 3;
    numPeople -= 2;
    numPeople -= 4;
    numPeople += 5;

    System.out.println("Current: " + numPeople);
    System.out.println("First: " + firstCount);
  }
}

Expected outputCurrent: 7 First: 5

  1. Evaluate the right side using the current value.
  2. Store the result in the left-side variable.

Explain: variable and initialization

A variable is a named item that holds one current value. int numPeople = 5; declares an integer variable and gives it its initial value.

Explain: assignment is an action

= is not mathematical equality. Java evaluates the right side, then overwrites the one variable on the left. Lower camel case makes a multiword identifier readable.

Deliberate compile-time error: type numPeople + 3 = numPeople;. The compiler rejects it because the left side of assignment must be one variable. Undo it and restore the last working version.
Transfer check: If int snapshot = numPeople; is added immediately after numPeople += 3;, what is snapshot at the end? Answer: 8.

public class TimeBreakdown {

Explain: expression

An expression combines values and operators and evaluates to one value. With two int operands, / returns only the whole-number quotient.

Explain: precedence

Parentheses run first, then unary minus, then * / %, then + -. Equal-precedence operators evaluate left to right. Use extra parentheses when they make intent clearer.

Common logic mistake: minutes = totalSeconds / 60; calculates 122 total minutes, not the minutes remaining after complete hours. Decompose the problem in stages.

3. Integer versus floating-point division

Source sections 2.7 and 2.12

Students will learn

Predict division from operand types and cast before division to preserve a fractional result.

Problem

A student earned 175 total points across 2 attempts. The average should be 87.5, but the first Java calculation prints 87.0. Find where the fraction is lost and repair the expression.

Ask before running

"Does the type on the left control division, or do the operand types on the right control it?"

Expected claim

The operands control the operation before assignment occurs.

Type: AverageDemo.javabegin with the fraction-losing version

public class AverageDemo {
  public static void main(String[] args) {
    int totalPoints = 175;
    int attempts = 2;

    double average = totalPoints / attempts;
    System.out.println("Average: " + average);
  }
}
public class AverageDemo {
  public static void main(String[] args) {
    int totalPoints = 175;
    int attempts = 2;

    double wrongAverage =
        totalPoints / attempts;
    double rightAverage =
        (double) totalPoints / attempts;

    System.out.println("Wrong: " + wrongAverage);
    System.out.println("Right: " + rightAverage);
    System.out.printf("Formatted: %.2f%n",
        rightAverage);
  }
}

Expected outputWrong: 87.0 Right: 87.5 Formatted: 87.50

Trace the types before the valuesoperation happens first

  1. totalPoints is int; attempts is int.
  2. 175 / 2 therefore uses integer division and becomes 87.
  3. Assignment converts 87 to 87.0. The discarded 0.5 cannot return.
  4. (double) totalPoints becomes 175.0 before division.
  5. One double operand makes the operation floating-point: 175.0 / 2 = 87.5.
ExpressionOperation typeValue
175 / 2int87
(double) 175 / 2double87.5

Explain: choose a type by meaning

Use int for whole-number counts and double for measurements or results that may contain a fraction. A decimal literal such as 2.0 is a double.

Explain: conversion and formatting

A cast requests an explicit conversion. Cast before the operation that needs a fraction. printf("%.2f", value) rounds the displayed text; it does not change the stored value.

Common repair that is still wrong: (double) (totalPoints / attempts). The parentheses force integer division first; the late cast changes only 87 into 87.0.
Transfer check: Why does double area = (1 / 2) * base * height; produce zero? Repair it. Answer: 1 / 2 is integer zero; use 0.5 * base * height or (double) 1 / 2 * base * height.

4. Scanner, String, and char

Source sections 2.16 and 2.17

Students will learn

Choose Scanner methods for numbers, full lines, and characters, then repair the leftover-newline bug.

Problem

Read age 19, full name Betty Sue McKay, and grade A. A first attempt uses nextInt() followed immediately by nextLine(), so the name appears empty. Explain the input state and fix it.

Ask before typing

"After nextInt() reads 19, what character is still waiting in the input buffer?"

Expected prediction

The newline from pressing Enter remains; the next nextLine() consumes that empty remainder.

Type: StudentInput.javastart with the newline bug

import java.util.Scanner;

public class StudentInput {
  public static void main(String[] args) {
    Scanner scnr = new Scanner(System.in);

    System.out.print("Age: ");
    int age = scnr.nextInt();

    System.out.print("Full name: ");
    String fullName = scnr.nextLine();

    System.out.print("Grade: ");
    char grade = scnr.next().charAt(0);

    System.out.println("Saved: " + fullName +
        ", age " + age + ", grade " + grade);
  }
}

  1. Choose a method based on the shape of the required input.
  2. Token methods stop at whitespace; line methods stop at newline.
  3. Consume a pending newline only when switching from token input to line input.

Explain: one token versus one line

next() skips leading whitespace and reads one token. nextLine() reads the remaining characters up to the newline, including spaces inside a full name.

Explain: String versus char

A String is a sequence of characters written with double quotes. A char stores one character written with single quotes. charAt(0) selects the first character of a token.

Break it deliberately: comment out the discard call. The name becomes empty, then next() reads Betty and the grade becomes 'B'. Restore the call, rebuild, and rerun the exact same input.
Transfer check: If the input is Ali Alotaibi, what does next() return and what does nextLine() return when each starts at the beginning of the line? Answer: "Ali" and "Ali Alotaibi".

5. Methodical debugging and Math

Source sections 2.4, 2.10, and 2.22

Students will learn

Use a prediction, focused test, and operator trace to diagnose a logic error involving Math.

Problem

A circle has circumference 10.0 and 12 equal sectors. The radius should be near 1.59, but circumference / 2 * Math.PI produces 15.71. Diagnose the cause, then calculate radius, area, and degrees per sector.

Ask before editing

"The program compiled and finished. What kind of error is this, and what single intermediate value would test your hypothesis?"

Expected prediction

The full denominator should be about 6.28; radius should be between 1 and 2.

Type: CircleDebug.javastart with the grouping bug

public class CircleDebug {
  public static void main(String[] args) {
    double circumference = 10.0;
    int sectorCount = 12;

    double radius = circumference / 2 * Math.PI;
    double area = Math.PI * Math.pow(radius, 2);
    int degreesPerSector = 360 / sectorCount;

    System.out.printf("Radius: %.2f%n", radius);
    System.out.printf("Area: %.2f%n", area);
    System.out.println("Degrees per sector: " +
        degreesPerSector);
  }
}
public class CircleDebug {
  public static void main(String[] args) {
    double circumference = 10.0;
    int sectorCount = 12;

    double radius =
        circumference / (2 * Math.PI);
    double area =
        Math.PI * Math.pow(radius, 2);
    int degreesPerSector = 360 / sectorCount;

    System.out.printf("Radius: %.2f%n", radius);
    System.out.printf("Area: %.2f%n", area);
    System.out.println("Degrees per sector: " +

  }
}

Expected outputRadius: 1.59 Area: 7.96 Degrees per sector: 30

Debugging walkthroughone testable cause at a time

  1. Observe: wrong radius 15.71; no compilation or runtime failure.
  2. Predict: / and * have equal precedence and run left to right.
  3. Test: print 2 * Math.PI; the denominator is 6.28319.
  4. Trace bug: 10.0 / 2 * PI becomes 5.0 * PI.
  5. Fix: group the complete denominator: 10.0 / (2 * PI).
  6. Verify: rerun the same input and compare with the predicted range.
System.out.printf("Denominator: %.5f%n", 2 * Math.PI); // Denominator: 6.28319

Explain: method call

Math.pow(radius, 2) passes two argument values to a method and evaluates to the returned square. Math.PI is a case-sensitive library constant.

Explain: debugging loop

Repeat: observe, predict one cause, devise a focused test, keep or reject the prediction, fix, and rerun the same input. Avoid random edits that hide the evidence.

6. Constants, long, and intermediate values

Source sections 2.6, 2.9, 2.12, and 2.18-2.19

Students will learn

Estimate numeric ranges, choose int or long, and convert before multiplication to prevent overflow.

Problem

Using the simplified assumptions 365 days/year, one extra day per four complete years, 1,440 minutes/day, and 72 beats/minute, estimate lifetime days, minutes, and heartbeats for age 80. Choose types that keep every intermediate result valid.

Ask before typing

"Which result might exceed the maximum int, 2,147,483,647? Does a long destination protect an earlier int multiplication?"

Expected design

Keep age and days as int; force minutes and heartbeats to be calculated as long.

Type: HealthData.javastart with overflowing int results

import java.util.Scanner;

public class HealthData {
  public static void main(String[] args) {
    final int DAYS_PER_YEAR = 365;
    final int MINUTES_PER_DAY = 24 * 60;
    final int BEATS_PER_MINUTE = 72;

    Scanner scnr = new Scanner(System.in);
    int ageYears = scnr.nextInt();

    int ageDays = ageYears * DAYS_PER_YEAR
        + ageYears / 4;
    int ageMinutes = ageDays * MINUTES_PER_DAY;
    int heartbeats = ageMinutes * BEATS_PER_MINUTE;

    System.out.println("Days: " + ageDays);
    System.out.println("Minutes: " + ageMinutes);
    System.out.println("Heartbeats: " + heartbeats);
  }
}
import java.util.Scanner;

public class HealthData {
  public static void main(String[] args) {
    final int DAYS_PER_YEAR = 365;
    final int MINUTES_PER_DAY = 24 * 60;
    final int BEATS_PER_MINUTE = 72;

    Scanner scnr = new Scanner(System.in);
    int ageYears = scnr.nextInt();

    int ageDays = ageYears * DAYS_PER_YEAR
        + ageYears / 4;
    long ageMinutes =

}

Explain: named constants

final prevents reassignment. Uppercase underscore names expose assumptions and remove unexplained repeated numbers. This leap-day rule is an estimate, not an exact calendar calculation.

Explain: overflow and early conversion

Integer overflow wraps instead of normally throwing an exception. A destination type cannot repair a product that already overflowed. Convert an operand before the risky operation.

Break it deliberately:int ageMinutesInt = ageDays * MINUTES_PER_DAY; int heartbeatsInt = ageMinutesInt * BEATS_PER_MINUTE;For age 80, the heartbeat result wraps to -1265437696. A negative lifetime count exposes the logic error.
Transfer checks: Age 19 produces 6939 days, 9992160 minutes, and 719435520 heartbeats, so a small test can hide the bug. The first whole age whose estimate exceeds int is 57.

Final instructor checklist

  • State the exact problem and required output first.
  • Ask for a prediction before every run.
  • Trace values or operand types in execution order.
  • Run one small change at a time.
  • Use the same input before and after a repair.
  • Keep compiler and Console evidence visible.
  • Name the governing concept after the evidence.
  • End with the transfer check, not another lecture recap.
