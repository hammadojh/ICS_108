Values, types, and state

Chapter abstract

A Java program moves through a sequence of states. Variables hold the current values, expressions produce new values, and data types determine which values are possible and how operators behave. Most mistakes in this chapter become explainable once you trace the value, its type, and the moment it is stored.

Concept 01Source §§2.1–2.3, 2.5

Variables and assignment describe changing state

A variable is a named storage location with one current value. A declaration introduces its type and name; initialization gives its first value. An assignment is an action: Java evaluates the expression on the right, then stores the resulting value in the single variable on the left.

Keep in mind

Read numPeople = numPeople + 3; as “read the old value, calculate the new value, then overwrite the variable.” It is not a statement of mathematical equality.

Expand the state modeltrace, copies, identifiers, and common errors

Execution is sequential

Each statement observes the state left by the statement before it. Compound assignment such as numPeople += 3; is a concise read–calculate–store operation.

StatementCurrent countSaved count

Primitive assignment copies a value

When one int variable is assigned to another, the current numeric value is copied. No live connection remains between the two variables.

Names and initialization matter

  • Identifiers may contain letters, digits, underscores, and dollar signs, but cannot start with a digit.
  • Java names are case-sensitive; reserved words cannot be identifiers.
  • Lower camel case communicates ordinary variable names.
  • A local variable must be assigned before its value is read.
Common confusionnumPeople + 3 = numPeople; is invalid because the left side must identify one assignable storage location, not a calculated expression.
Useful teaching sentence“The right side is a question Java answers; the left side is the one place where Java stores the answer.”

Concept 02Source §2.4

Expressions produce one value

An expression combines literals, variables, operators, and method calls and evaluates to one value. Parentheses express intentional grouping. Without parentheses, Java follows its precedence rules; operators at the same precedence level evaluate from left to right.

Keep in mind

For this chapter: parentheses first, then unary minus, then * / %, then + -. Precedence determines the shape of the calculation before any assignment occurs.

Expand expression evaluationprecedence, associativity, grouping, and a circle trace

Precedence is not importance

Precedence is a parsing rule that tells Java which operation belongs together first. It does not mean multiplication is conceptually more important than addition.

  1. Evaluate the innermost parentheses.
  2. Apply higher-precedence operators.
  3. For equal precedence, move left to right.
  4. Use the resulting value in the surrounding expression.

Why the circle formula fails

double radius = circumference / 2 * Math.PI;

Because / and * have equal precedence, 10.0 / 2 * Math.PI becomes 5.0 * Math.PI, or about 15.71. The intended formula needs the complete denominator grouped:

double radius = circumference / (2 * Math.PI);
Common confusionReading a familiar mathematical formula from memory can hide the grouping Java actually performs. Trace the operators in execution order.
Useful teaching sentence“Parentheses are not decoration; they make the intended sub-calculation explicit.”

Concept 03Source §§2.11–2.12

Division behavior comes from the operands

When both operands are integers, Java performs integer division and discards the fractional part; for positive values, 7 / 2 is 3. Modulo, written %, returns the remainder. Together, quotient and remainder decompose totals into complete groups and what remains.

Keep in mind

/ answers “how many complete groups?” and % answers “what remains?” Use the remainder before decomposing the next smaller unit.

Decompose from the largest unit

QuestionExpressionResult
Complete hours7325 / 36002
Seconds after hours7325 % 3600125
Complete minutes125 / 602
Remaining seconds125 % 605

The final result is 2:2:5. Calculating 7325 / 60 instead gives total minutes, not minutes remaining after the hours.

Important boundaries

  • Integer division truncates toward zero.
  • Integer division by zero throws ArithmeticException.
  • Floating-point division by zero produces Infinity or NaN.
  • (1 / 2) becomes integer zero before it participates in a wider expression.
// zero is produced first
double area = (1 / 2) * base * height;

// preserve the fraction
double area = 0.5 * base * height;
Useful teaching sentence“Before dividing, identify the type of each operand—not the type of the destination variable.”

Concept 04Source §§2.7, 2.12

Choose a numeric type from meaning and range

int models whole-number counts within its range, long models larger whole-number counts, and double models measurements or calculations that may contain a fraction. A cast changes the type of a value; it must occur before the operation whose behavior needs to change.

Keep in mind

A double variable on the left does not force floating-point division on the right. Java evaluates the right side first using the operand types it already has.

Expand numeric types and conversionearly casts, late casts, formatting, and precision

The average example

int totalPoints = 175;
int attempts = 2;

double wrong = totalPoints / attempts;          // 87.0
double late  = (double) (totalPoints / attempts); // 87.0
double right = (double) totalPoints / attempts; // 87.5

In the first two expressions, 175 / 2 becomes integer 87 before conversion. In the last expression, one operand becomes 175.0 before division, so the operation is floating-point.

Conversion and presentation differ

  • An implicit conversion from int to double preserves the integer value.
  • An explicit cast to int truncates the fractional part.
  • printf("%.2f", value) rounds the displayed text, not the stored value.
  • Floating-point values are approximations; they are not always suitable for exact currency calculations.
Common confusionCasting the completed quotient is too late. A conversion can change a value’s type, but it cannot reconstruct a fraction already discarded by integer division.
Useful teaching sentence“Change an operand before the operation, not the answer after the operation.”

Concept 05Source §§2.9–2.10

Constants communicate assumptions; methods package calculations

A constant variable is initialized once and cannot be reassigned. The final keyword lets the compiler protect an assumption, while an uppercase underscore name explains its meaning. A method call supplies argument values and evaluates to the method’s returned value.

Keep in mind

Use named constants for values that carry meaning or repeat. Use a method when Java already provides the calculation, and check the required number and order of arguments.

Expand constants and Mathsyntax, method anatomy, and circle calculations

Named assumptions

final int DAYS_PER_YEAR = 365;
final int MINUTES_PER_DAY = 24 * 60;
final int BEATS_PER_MINUTE = 72;

The names reveal the model. They also centralize changes and prevent accidental reassignment after initialization.

Method and constant members

  • Math.sqrt(49.0) returns 7.0.
  • Math.pow(radius, 2) returns the square of radius.
  • Math.abs(-99.5) returns 99.5.
  • Math.PI is a case-sensitive library constant.

The Math class requires no import. Method names, argument count, argument order, and capitalization must match the API.

Common confusionMath.Pi does not name the same member as Math.PI. Java is case-sensitive.
Useful teaching sentence“A constant names a stable fact in our model; a method turns input values into a returned value.”

Concept 06Source §§2.16–2.17

Text types and input methods model different boundaries

A char stores one character literal written in single quotes; a String represents a sequence of characters written in double quotes. Scanner token methods stop at whitespace, while nextLine() reads through the end of the current line.

Keep in mind

Choose the input method from the shape of the required value, then account for what that method leaves unread in the input buffer.

Why the name becomes empty

After the user enters 19 and presses Enter, nextInt() returns 19 but leaves the newline. An immediate nextLine() reads the empty remainder before that newline.

int age = scnr.nextInt();
scnr.nextLine();       // discard pending newline
String name = scnr.nextLine();
char grade = scnr.next().charAt(0);
Common confusionThe extra nextLine() is not a ritual that belongs after every numeric read. It is needed specifically when a pending newline would otherwise be consumed by a following line read.
Useful teaching sentence“A Scanner method returns one value and leaves the rest of the input waiting.”

Concept 07Source §§2.18–2.19

Range applies to intermediate results too

An int is a 32-bit signed whole number with a maximum of 2,147,483,647; a long provides a much larger 64-bit range. Overflow occurs when an operation produces a value outside the selected type’s range. It usually wraps to an incorrect value instead of stopping the program.

Keep in mind

A wide destination does not protect a narrow calculation. Convert an operand before a multiplication that may overflow.

Expand range and overflowHealthData trace, early conversion, and boundary tests

The risky calculation

int ageDays = 29220;
int ageMinutesInt = ageDays * 1440;

// both operands are int; overflow happens first
long wrong = ageMinutesInt * 72;

// one long operand makes the product long
long right = (long) ageMinutesInt * 72;

In HealthData, age 80 produces 3,029,529,600 estimated heartbeats, which exceeds Integer.MAX_VALUE. Converting when minutes are calculated keeps that value—and the later heartbeat multiplication—in long.

Tests should expose the boundary

  • Age 19 remains within int, so it can hide the defect.
  • Age 57 is the first whole age whose heartbeat estimate in this simplified model exceeds int.
  • Age 80 makes the broken int result negative, a strong clue that range—not the real-world quantity—is wrong.

Range reasoning belongs before implementation: estimate the largest plausible magnitude, then choose the type.

Common confusionlong result = intValue * intValue; can still overflow because the two int operands determine the multiplication type before assignment to long.
Useful teaching sentence“The operation needs enough range at the moment it runs—not only after the result is stored.”

Concept 08Source §§2.6, 2.22

Debugging turns a wrong result into a testable explanation

A compile-time error prevents a successful build, a runtime error interrupts execution, and a logic error allows the program to finish with the wrong result. Methodical debugging observes the evidence, predicts one cause, designs a focused test, and uses the result to keep or reject that explanation.

Keep in mind

Change one relevant thing, rerun the same input, and compare against a predicted value or range. Random edits destroy the evidence you need.

Expand the debugging methoderror categories, focused tests, and integration

The loop

  1. Observe. State the actual output and the expected output precisely.
  2. Predict. Name one possible cause grounded in the code.
  3. Test. Print one intermediate value, isolate one expression, or substitute one known value.
  4. Decide. Keep or reject the prediction based on the evidence.
  5. Fix and verify. Make the smallest repair and rerun the original input.
