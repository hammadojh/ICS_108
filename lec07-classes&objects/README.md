# ICS 108 Lecture 7 — Classes and objects

A roughly 30-minute lecture built around three extensions of one campus wallet program.

- [Student problems](student-problems.md): short, solution-free prompts and exact expected output.
- [Supporting slides](slides/index.html): 17 slides, including 11 simple concept definitions.
- [Instructor handout](instructor/walkthroughs.html): three printable A4 pages, complete syntax-colored solutions, Copy problem and Copy complete code controls.
- [Concept refresher](instructor/concept-refresher.html): plain summaries and expandable instructor explanations.
- [Java examples](examples/README.md): complete runnable snapshots of each extension.
- [Content map](docs/CONTENT_MAP.md): source coverage, timing, additions, and deferred depth.

| Problem | Extension | Program | Supporting slides |
|---|---|---|---|
| 1 | Store and display one balance | CampusWallet1.java | 3–8 |
| 2 | Add money to that wallet | CampusWallet2.java | 9–12 |
| 3 | Give two students independent wallets | CampusWallet3.java | 13–16 |

Start with the student prompt and let students decide how to solve it. Use the concept definitions as needed, then develop the instructor solution in the IDE. The numbered Java files are independent snapshots of the same evolving design; they compile together. Problems 2 and 3 reuse the earlier behavior. Problem 1 exposes the field for the first small step; Problem 2 introduces private data and public operations; Problem 3 preserves those operations and adds constructor initialization.

All pages work offline without a build step. Complete code is visible by default, its syntax colors are embedded in the HTML, and copying returns plain Java. Copy problem includes only the student prompt and output. Print the handout for three A4 pages. The refresher expands details for printing.

Slide controls: Arrow/Page keys, Space/Enter, Backspace, Home/End, and buttons. A reveal is shown before advancing; interactive controls do not navigate the deck. The final slide offers one brief check.
